Activity Diagram

This activity diagram represents the overall process of the Money Exchange System.

Process:
1.The customer logs in or registers in the system.
2.The customer can then view the main menu.
3.The customer makes a request for a currency exchange.
4.The system checks whether the customer exists. If the customer does not exist, the customer needs to register before proceeding.
5.If the customer exists, the process continues. The customer enters the currency details, including the FROM currency, TO currency, and exchange amount.
6.The system checks whether an exchange rate is available. If an exchange rate is not available, the system displays a "Rate is not available" message. If the rate is available, the system calculates and displays the converted amount.
7.The system saves the exchange transaction.
8.The system issues a receipt.
9.Finally, the system returns to the main menu.
